# 2italy Website

This project is now migrated from static HTML into a Next.js app.

## What changed
- Converted the site into a Next.js project under `app/`
- Added shared navigation and footer components
- Added page routes for `/`, `/resources`, `/universities`, `/consultation`, and `/tutorial`
- Copied `brand-assets/` into `public/brand-assets`
- Installed dependencies and verified the site builds successfully

## Run locally
```bash
npm install
npm run dev
```

Open http://localhost:3000 to preview the site.

## Deploy
This repo is already connected to a GitHub remote. Deploy it on Vercel by pointing to this repository.
